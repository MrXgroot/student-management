# Workflow Index

Each workflow document should define actors, preconditions, main path, alternate paths, state transitions, side effects, permissions, audit requirements, errors, and tests.

Planned workflows:
1. `admissions.md` — application submission, verification, decision, offer acceptance and enrollment handoff
2. `student-enrollment.md` — student record, term registration, course enrollment and withdrawal
3. `attendance.md` — class session, attendance register, correction and reports
4. `fees-and-payments.md` — fee setup, obligation creation, collection, receipt, reversal and reconciliation
5. `examinations-and-results.md` — exam setup, eligibility, marks, moderation, approval, publication and amendment
6. `progression-and-graduation.md` — term completion, backlog, promotion and graduation eligibility

Do not implement a workflow until its state transitions and invariants are documented and reviewed.
